feat(ui): v3「档案鼓」— 3D 仪表 + 单条直接清理 + 批量一次确认 + 除尘高潮动画

用户三条要求全部落地：

1) 确认流程改革（可逆的事不再反复打字）
   - 每条可清项自带「清理」动作：点一下 → 卡内弹出这一条的确认（名称 + 体量 + 去废纸篓 + 可逆）→ 再点一下执行
   - 全选后「清理选中的 N 项（X GB）」→ 底部确认闸门摊开清单与合计 → 一次点击执行
   - 只有不可逆的「清空废纸篓」保留手打确认语
   - 后端契约不变：apply 仍带 confirm="确认清理"（由界面在用户点击确认后填入）；选择仍只做交集

2) 清理动画做成高潮段落
   卡片升起 → 散成灯下尘埃 → 螺旋吸入档案鼓 → 冲击波 + 闪光 → 液位下降 → 可用空间逐帧跳格 →
   每行盖上「已退役」章；全部按时间推进（低帧率环境下也会按时到位），reduced-motion 下自动关掉

3) 界面飞跃：真 3D 软件渲染的「档案鼓」
   - 鼓里立着清单里的每一项（卡的高度＝体量对数刻度，颜色＝三档归属；被抽出来发亮的就是勾选的）
   - 液位＝磁盘占用：带圆盘液面、亮边、「液位 xx%」读数；上口 40 格刻度
   - 左右轮廓 + 上下鼓口 + 实体底座与投影，可拖动转动、有指针视差；相机/姿态有 NaN 兜底
   - 数字下面给读数让位的暗纱（不是装饰）

其他：卡片厚度与上边缘高光、面板 tabs、?debug=1 下的 __drum 调试钩子（把动画状态钉死后截图核对）

验证：impeccable detect 0 条；--selftest 10/10；浏览器实测单条清理请求只带那一条路径、
批量请求带全部勾选项、错误确认语被拒且什么都没删；桌面 1440 / 手机 390 无横向溢出
